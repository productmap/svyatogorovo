## SEO и поисковое продвижение

### Сделано
- Lighthouse 100/100/100/100
- Schema.org JSON-LD: TouristAttraction, LodgingBusiness, LocalBusiness, FAQPage, BreadcrumbList, GeoCoordinates
- sitemap.xml с изображениями (image namespace)
- robots.txt с директивой Host для Яндекса
- Яндекс Турбо RSS (`/turbo.rss`)
- Гео-метатеги (geo.region, geo.placename, geo.position)
- PWA manifest + apple-touch-icon + theme-color
- og:image:alt
- fetchpriority="high" на LCP-изображение
- CSS инлайнится в HTML (нет render-blocking ресурсов)
- WebP + lazy loading + sizes + width/height на всех изображениях

## Работа с турагентствами

### Целевые агентства
- Православный и паломнический туризм: «Радонеж», «Пилигрим», Паломнический центр Московской Патриархии
- Эко- и сельский туризм
- Семейный выездной отдых
- Корпоративные ретриты

### Что нужно подготовить
- [ ] Медиакит (PDF): фото, вместимость, инфраструктура, цены, контакт
- [ ] Готовые пакеты-маршруты: «День паломника», «Выходные в Святогорово», «Семейный лагерь»
- [ ] Комиссионная схема для партнёров
- [ ] Раздел «Для партнёров» на сайте с B2B-контентом

### Каналы выхода на агентства
- АТОР и РСТ — выставки MITT и «Интурмаркет» в Москве (прямой контакт)
- Паломнические конференции при епархиях и монастырях
- Борисоглебский монастырь — точка входа в паломническую сеть
- Министерство туризма Московской области — реестр объектов (бесплатно)

### Ключевой принцип
Святогорово — место с подлинной историей, не коммерческий объект.
Тон коммуникации: личное знакомство, а не холодные рассылки.

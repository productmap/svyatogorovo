# Production-ready SVG (для Illustrator)

В отличие от `mockups/signs/*.svg` (визуальные эскизы для согласования и
презентации), файлы в этой папке готовы к импорту в Adobe Illustrator и
дальше — в производственные процессы (резка плёнки, печать, фрезеровка
ACP-панелей).

| Файл | Физический размер | QR-кодов | Якорь лендинга |
|---|---|---|---|
| `T1-entry-stand.svg` | 2000 × 1500 мм | 1 | `/` (главная) |
| `T2-stela.svg` | 600 × 1200 мм | 1 | `/#sergiy` |
| `T3-indicator.svg` | 900 × 1300 мм | 3 | `/#krest`, `/#church`, `/#guest` |
| `T4-plaque-cross.svg` | 800 × 600 мм | 1 | `/#krest` |
| `T4-plaque-chapel.svg` | 800 × 600 мм | 1 | `/#church` |
| `T4-plaque-spring.svg` | 800 × 600 мм | 1 | `/#kupel` |
| `T5-rest-area.svg` | 400 × 400 мм | — | — |
| `T6-guesthouse.svg` | 900 × 450 мм | 1 | `/#guest` |

Все файлы автоматически генерируются скриптом `scripts/build-production-signs.py`
из соответствующих мокапов в `../mockups/signs/`. Регенерация — одной командой:

```bash
python3 scripts/build-production-signs.py
```

## Что делает файл «production-ready»

| Свойство | Mockup | Production |
|---|---|---|
| Корневые `width`/`height` | без единиц | `Xmm × Ymm` (физический размер) |
| `viewBox` | произвольный | совпадает с физическими размерами |
| Координаты | абстрактные | миллиметры (1 unit = 1 mm) |
| Артборд после импорта в AI | произвольный | точно нужного размера в мм |
| Цвет | hex `#714A07` | hex + указание Pantone/CMYK/RAL в шапке-комментарии |
| Шрифты | font-family fallback | font-family + инструкция «Create Outlines перед сдачей» |
| QR | стилизованная заглушка | **настоящий QR-код**, генерируется на якорь лендинга |
| Пиктограммы | hand-drawn (исторически) | официальные из Методички, векторизованы potrace |
| Сетка построения | нет | скрытый слой M = 25 мм для проверки модульности |

## Чек-лист после открытия в Illustrator

1. **Проверить артборд.** Должен быть точно нужного размера в мм
   (см. таблицу выше). Если другой — что-то пошло не так с импортом.
2. **Проверить шрифт.** При отсутствии Myriad Pro Condensed AI покажет
   диалог замены. Установить Myriad Pro из Creative Cloud (входит в подписку
   по умолчанию).
3. **Type → Create Outlines** на все надписи перед сдачей в типографию.
   После этого файл будет рендериться идентично где бы его ни открыли.
4. **Проверить QR-коды.** Каждый должен открываться при сканировании
   мобильным и вести на правильный якорь лендинга (см. таблицу выше).
5. **Проверить цвет.** Слой sign-body должен быть Pantone 731 C
   (для офсетной печати) либо CMYK 34/65/100/43 (для цифровой).
6. **Снять draft-метки.** Тонкие подписи «T2 · STELA · DRAFT v0.1»
   внизу каждого знака — для рабочей отладки. Удалить перед печатью.
7. **При желании раскрыть `#construction-grid`** — увидите модульную
   сетку M = 25 мм, на которой построен знак.

## Стандарты-источники

Все production-файлы соответствуют:

- **ГОСТ Р 57581-2017** «Туристские услуги. Информационные знаки системы
  навигации в сфере туризма. Общие требования.»
- **Методическое пособие** Минкультуры РФ (2013, согласовано с Минкомсвязью,
  Минрегионом, Минтрансом) — раздел 3.2 (цвет), 3.3 (шрифт), 3.4 (построение),
  3.5 (пиктограммы), 3.6 (построение знаков-указателей).
- **ГОСТ Р 52290-2004** «Знаки дорожные» — в части модульной сетки M = 25 мм.

## Технология построения

`scripts/build-production-signs.py` для каждого мокапа:

1. Парсит `viewBox`, добавляет `width="Xmm" height="Ymm"` к корневому `<svg>`.
2. Вставляет производственный заголовок-комментарий с инструкциями.
3. По данным `SIGN_QRS` в скрипте генерирует **настоящие QR-коды**
   (библиотека `qrcode`) и накладывает поверх плейсхолдеров в мокапе.
4. Добавляет скрытый слой `#construction-grid` (модульная сетка M = 25 мм).

URL'ы QR-кодов хранятся в скрипте — если на лендинге появятся новые якоря или
изменятся существующие, правится одно место. Регенерация мгновенная.

## Если нужно отрегенерировать

```bash
# 1. Если поменялись пиктограммы (например, новые в Методичке):
python3 scripts/extract-pictograms.sh   # извлечь PNG из PDF
python3 scripts/trace-pictograms.py     # векторизовать через potrace

# 2. Если поменялась структура знака — правим mockups/signs/*.svg.

# 3. Если поменялись URL'ы QR — правим SIGN_QRS в build-production-signs.py.

# 4. Регенерируем production:
python3 scripts/build-production-signs.py
```

# Дизайн-система знаков

Документ фиксирует визуальные стандарты, обязательные для всех знаков проекта.
Все параметры в этом разделе **жёсткие**: они продиктованы ГОСТ Р 57581-2017 и
утверждённой Минкультуры Методичкой (2013). Отступления от этих параметров
лишают знаки правовой основы (Методичка стр. 6, прямая ссылка на ГОСТ 52290).

## 1. Цвет

### Основной (фон знака)

Коричневый, эталон по Pantone Matching System.

| Модель | Значение | Применение |
|---|---|---|
| **Pantone** | `731 C` | первичный эталон, для печати на плёнке |
| **CMYK** | `C34 M65 Y100 K43` | офсетная и цифровая печать |
| **RGB** | `R113 G74 B7` (`#714A07`) | электронные носители, лендинг |
| **RAL** | `8008 Olivebrown` | лакокрасочные покрытия |

### Дополнительный (графика и текст)

**Белый** — пиктограммы, текст, рамки. Без оттенков серого.

### Корпус (оборотная сторона, опоры, крепления)

**Серый** — Методичка стр. 15. Допускается оставлять оцинкованную поверхность
без покраски (но не блестящую — матовый или полуматовый финиш).

> ⚠ Запрещено использовать любые другие фоновые цвета. «Дизайнерские» отступления
> (например, тёмно-зелёный «под лес») делают знак нелегитимным для согласования
> с уполномоченным органом МО.

## 2. Шрифт

**Myriad PRO Condensed** — гарнитура Adobe (1992, гуманистический гротеск).

| Начертание | Применение |
|---|---|
| **Bold Condensed** | основное: названия объектов, ключевые блоки |
| **Condensed (Regular)** | вспомогательное: расстояния, второстепенный текст, англ. перевод |

### Иерархия на знаке

- **Заголовок** (название объекта): Bold Condensed, прописные.
- **Подзаголовок** (англ. перевод названия): Condensed Regular, прописные,
  размер ≈ 60% от заголовка.
- **Расстояния / основной текст**: Bold Condensed (для цифр), Regular (для текста).

> Если у заказчика нет лицензии на Myriad PRO, методически-приемлемая замена —
> **PT Sans Narrow / PT Sans Caption** (опен-сорс, поддерживает кириллицу,
> близкая ритмика). В пакете на согласование указывается именно Myriad PRO как
> рекомендованный Методичкой; решение о замене принимается на этапе производства.

## 3. Модульная сетка

Все пиктограммы и компоновки знаков строятся на основе **модульной сетки
ГОСТ Р 52290-2004** (Методичка стр. 21). Это означает:

- Базовая единица сетки — квадратный модуль `M`.
- Пиктограмма вписана в поле `12M × 12M` (типовой формат).
- Поля по краям знака — `1M`.
- Минимальный размер пиктограммы для дальнего считывания — `400 × 400 мм`
  при `M = 25 мм`.

Конкретные размеры знаков под каждый тип — в `03-tech-spec/dimensions.md`.

## 4. Принципы построения макета

### Структура знака маршрута (типовая)

```
┌────────────────────────────┐ ← 1M верхнее поле
│                            │
│        [пиктограмма]       │ ← 12M × 12M основной модуль
│                            │
├────────────────────────────┤ ← разделительная линия 0,3M
│      НАЗВАНИЕ ОБЪЕКТА      │ ← Bold Condensed
│       OBJECT NAME EN       │ ← Regular Condensed
└────────────────────────────┘ ← 1M нижнее поле
```

### Структура указателя направления (стрелка)

По Методичке гл. 3.6 (предстоит прочитать детально). Базовая логика:

```
┌────────────────────────────┐
│ ← [pict]  ПОКЛОННЫЙ КРЕСТ  │
│           1,2 КМ            │
├────────────────────────────┤
│ → [pict]  ЧАСОВНЯ НИКОЛАЯ  │
│           400 М             │
└────────────────────────────┘
```

### Минимальное расстояние между элементами

- Между пиктограммой и текстом: `≥ 1M`.
- Между строками текста: интерлиньяж `1,15M`.
- Между блоками (если на указателе несколько направлений): `1M` разделитель
  + `0,3M` тонкая линия.

## 5. Скруглённые углы

Знак имеет **скруглённые внешние углы** (видно на всех образцах Методички,
с. 22-45): радиус скругления `≈ 1M` (около 25 мм при типовом масштабе). Это не
случайность — это та же визуальная мягкость, которую требуют пешеходные
туристские системы (vs. строгая прямоугольность дорожных знаков).

## 6. QR-код

QR-код размещается **в правом нижнем углу** знака, на белой подложке (для
надёжного считывания).

- Размер белой подложки: `3M × 3M` (≈ 75 × 75 мм).
- Размер самого QR-кода: `2,4M × 2,4M` (≈ 60 × 60 мм) внутри подложки.
- Контент QR — короткая ссылка на якорь лендинга (`https://святогорово.рф/#krest`,
  `/#church` и т. д.). Подробнее: `06-content/qr-content.md`.

## 7. Применимость к разным носителям

ГОСТ 57581 (пункт 4.3) делит знаки на три группы — система должна быть
**визуально идентичной** во всех трёх:

1. **На дорогах** — стационарные знаки на опорах, ГОСТ 52290 модульная сетка,
   световозвращающая плёнка.
2. **На территории объекта** — стационарные знаки на опорах, либо настенные
   таблички.
3. **В печатных и электронных материалах** — карты, путеводители, лендинг.
   Тот же цвет, шрифт, пиктограммы.

> Для лендинга это означает: иконки разделов «Поклонный крест», «Часовенка»,
> «Тропа Сергия» в идеале должны быть приведены к той же пиктографической
> системе (`#48 var.3`, `#48 var.2`, `#38`). Это даёт цельность бренда тропы
> в физике и цифре.

## 8. Что НЕ допускается

- ❌ Любые цвета фона кроме указанного коричневого.
- ❌ Чёрный текст на коричневом (только белый).
- ❌ Тонкие линии < 0,3M — теряются при дальнем считывании.
- ❌ Стилизованные «русские» шрифты (славянская вязь, имитация устава) —
  Методичка явно требует Myriad PRO.
- ❌ Декоративные элементы (вензели, орнаменты, фоновые узоры).
- ❌ Изображения людей (фото) на знаках маршрута — только пиктограммы.
- ❌ Логотипы спонсоров на знаках навигации (запрет рекламного использования).

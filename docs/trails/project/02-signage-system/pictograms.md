# Палитра пиктограмм

Из 49+ пиктограмм Методички (раздел 3.5) для проекта отобрана **минимально
достаточная палитра** — каждая пиктограмма должна быть обоснованно нужна.
Избыток пиктограмм перегружает систему и противоречит принципу «знаков ровно
столько, чтобы тропа была проходима».

Номера соответствуют Методичке (Минкультуры РФ, 2013).

## Основная палитра (Фаза 1, обязательные)

### Маршрут

| # | Название | Применение в проекте | Графический образ (по Методичке) |
|---|---|---|---|
| **38** | Пешеходный туристский маршрут / Tourist trail | **Главная пиктограмма проекта**. Используется на: въездном стенде, стелах начала и финиша Святогоровского отрезка, всех маршрутных указателях направления | Фигура человека с рюкзаком и палкой, пунктирный маршрут, финишный флажок |

### Религиозные объекты (пиктограмма #48 в трёх масштабах)

Методичка специально предусматривает **три варианта** для разных категорий
православных объектов — это критически важно для корректности проекта.

| Вариант | Применение в проекте | Графический образ |
|---|---|---|
| **48 (a)** Многокупольный собор | _Не используется_ на Святогоровском отрезке — нет соборов / монастырей. Резерв для Фазы 2 (Лавра, дмитровские соборы) | Многокупольный собор с православным крестом |
| **48 (b)** Церковь / часовня | **Часовенка Николая Чудотворца**. На указателе направления к ней и на самой табличке у часовни | Однокупольная церковь / часовня с крестом |
| **48 (c)** Локальный религиозный объект, место паломничества | **Поклонный крест**, **Купель**, любые малые памятные места на тропе. Методичка прямо упоминает этот вариант для «мест паломничества, памятных мест» | Православный крест на постаменте |

## Источники пиктограмм для производства

В пакет производства (07) должны попасть **векторные исходники** (SVG / EPS) каждой
используемой пиктограммы.

**Где взять (по приоритету):**

1. **Извлечь из самой Методички** (текущий путь проекта) — пиктограммы
   опубликованы как растровые тайлы в `docs/trails/Metod-Posobie.pdf`. Извлекаются
   через Poppler одной командой `pdfimages -png`. Скрипт-обёртка лежит в
   `scripts/extract-pictograms.sh`. **Сами по себе** пригодны для лендинга,
   эскизного проекта на согласование, мелких форматов печати. Уже извлечено
   10 пиктограмм проекта в `02-signage-system/mockups/pictograms/official/`.
2. **Трейс извлечённых растров в вектор** — для производства больших знаков
   (стелы 1,2 м, стенды 2 м) разрешения 467 px не хватает. Решение:
   `brew install potrace`, прогон по каждому файлу → чистые SVG-пути.
   Альтернатива: Adobe Illustrator → Image Trace.
3. **Идеально** — обратиться в Минкультуры РФ / Ростуризм с запросом на
   получение официального векторного набора (упомянут в Методичке как
   результат работы Федерального агентства по туризму, 2012). Если ответят,
   получится исходник без потери качества.
4. **Резерв** — построить пиктограммы заново по графическим образцам Методички.
   Уже сделано как промежуточный материал (`pictograms/*.svg`) — используется
   в композитных мокапах T1-T6 как блок без зашитой подписи. Это **законно**:
   ГОСТ и Методичка не закрепляют конкретный векторный файл, а описывают
   _содержание графического образа_.
5. **Запрещено** — использование изображений из коммерческих стоков
   «travel icons»: они не соответствуют образцам Методички и не имеют правовой
   опоры.

> Текущая стратегия проекта: путь 1 для эскизного проекта и лендинга
> (готово), путь 2 для производства (по мере необходимости). Путь 3 как
> бонус если получится — но не блокирующий.

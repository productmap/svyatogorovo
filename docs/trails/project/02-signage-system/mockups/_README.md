# Макеты знаков (черновики)

Папка содержит первые векторные эскизы для эскизного проекта:

```
mockups/
├── pictograms/   Многоразовые пиктограммы (12M × 12M, белое на коричневом)
├── signs/        Полные макеты знаков типа T1-T4
└── preview.html  Сводное превью всего набора — откройте в браузере
```

## Статус

⚠ **Это первый итерационный черновик.** Геометрия близка к образцам Методички
(стр. 22-45), но окончательные пиктограммы для производства должен отрисовать
профессиональный дизайнер в Adobe Illustrator с тщательной работой над
кривыми. Текущие SVG достаточны для:

- Эскизного проекта в пакете на согласование.
- Демонстрации концепции настоятелю и заказчику.
- Базы для дальнейшей итерации дизайнером.

## Размеры

Все SVG используют `viewBox="0 0 1000 1000"` (для пиктограмм-блоков) и
больший viewBox для композитных знаков. Это даёт **масштабонезависимость**:
один SVG корректно растрируется в любой размер для производства, для печати
и для лендинга.

## Цвета

- Фон: `#714A07` (Pantone 731 C / RAL 8008 Olivebrown).
- Графика и текст: `#FFFFFF`.

## Шрифт в SVG

```css
font-family: 'Myriad Pro Condensed', 'PT Sans Narrow', 'Arial Narrow', sans-serif;
```

При просмотре в браузере на компьютере без Myriad PRO шрифт упадёт на
PT Sans Narrow (опен-сорс, ставится бесплатно) или Arial Narrow. Это
нормально для черновика; для производства плёнка резапся / печатается
именно в Myriad PRO согласно ГОСТ 57581.

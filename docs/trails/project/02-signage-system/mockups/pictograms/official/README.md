# Официальные пиктограммы (извлечены из Методички)

PNG-файлы в этой папке извлечены **прямо из** `docs/trails/Metod-Posobie.pdf`
(Минкультуры РФ, 2013) и являются эталонной версией пиктограмм Общероссийской
системы туристской навигации. Используются как:

- **Авторитетный референс** для дизайнера, который будет финализировать
  векторные знаки для производства.
- **Готовые тайлы** для эскизного проекта в пакете на согласование — на
  этих изображениях видна полная Методичка-плитка: коричневый фон
  (Pantone 731 C), скруглённые углы, белая пиктограмма, билингва-подпись,
  типографика Myriad PRO Condensed.
- **Контент лендинга** — можно встраивать прямо в `index.html` через
  `<img src="…">` без дополнительной обработки.

## Технические параметры

- Формат: **PNG 32-bit RGBA**
- Размер: **467×467 px** (~50×50 мм @ 220 dpi в оригинале PDF)
- Извлечены с помощью `pdfimages -png` из Poppler

## Ограничения по использованию

- **Разрешение хватает** для лендинга, мелких форматов печати (до A4),
  эскизного проекта. Резерв качества при ресайзе вверх ≈ 1.5×.
- **Не хватает** для печати на больших стелах и стендах (T1 = 2 м, T2 = 1.2 м).
  Для производства такого формата нужен трейс растра в вектор. Варианты:
    - `brew install potrace` → `potrace -s` на каждый файл → чистый SVG.
    - Открыть в Adobe Illustrator → Image Trace → Expand → сохранить SVG.
    - Заказать у дизайнера полную ручную перерисовку по этим референсам.
- Подписи на изображении (например, «ПЕШЕХОДНЫЙ ТУРИСТСКИЙ МАРШРУТ»)
  **зашиты в растр** и не редактируются. Если для конкретного знака нужна
  своя подпись (например, на T3-указателе мы пишем «ПОКЛОННЫЙ КРЕСТ» вместо
  «РЕЛИГИОЗНЫЙ ОБЪЕКТ»), пиктограмму нужно перерисовать без подписи или
  обрезать нижнюю часть. До этого — используется наш hand-drawn SVG-вариант
  (`pictograms/*.svg`).

## Правовой статус

Методичка — официальный документ Министерства культуры РФ (2013), согласованный
с Минкомсвязью, Минрегионом и Минтрансом. Пиктограммы являются частью
официальной общероссийской системы и опубликованы для свободного применения.
Согласно ст. 1264 ГК РФ, официальные документы государственных органов не
являются объектами авторского права. Использование пиктограмм в проектах,
соответствующих ГОСТ Р 57581-2017, прямо предусмотрено самой Методичкой.

## Извлечь больше пиктограмм (все 49+)

В корне репозитория:

```bash
scripts/extract-pictograms.sh
```

Скрипт прогонит pdfimages по страницам 22-45 Методички и положит весь набор
во временную папку. Дальше можно вручную перенести нужные в `official/`
с правильными именами.

Связанные документы:
- `../README.md` — общее README мокапов.
- `../../pictograms.md` — палитра проекта с описанием каждой пиктограммы.

# Проект «Тропа преподобного Сергия Радонежского» — пакет документации

Документация проекта по организации паломнического маршрута, проходящего через
деревню Святогорово (Дмитровский район Московской области). Инициатор — приход
(РПЦ). Масштаб — полная навигационная система: знаки маршрута, интерпретация
у объектов, туристско-информационный центр, зоны отдыха, QR-коды на лендинг
и (опционально) аудиогид.

## Нормативная база

Проект целиком основан на трёх документах из `docs/trails/`:

| Документ | Уровень |
|---|---|
| **ГОСТ Р 57581-2017** «Туристские услуги. Информационные знаки системы навигации в сфере туризма» | закон |
| **Методическое пособие** Минкультуры РФ (2013, согласовано Минкомсвязью, Минрегионом, Минтрансом) | применение |
| **ГОСТ Р 52290-2004** «Дорожные знаки. Общие технические требования» | модульная сетка |

Дополнительно: ГОСТ Р 51885-2002 (ИСО 7001:1990) — общие символы общественных мест.

## Стратегия реализации (две фазы)

Маршрут как исторический объект — это путь **Дмитров → Святогорово → Троице-Сергиева
Лавра**, ~70 км. Согласовать его целиком за один заход нереально: пересекает
несколько муниципальных образований, разные владельцы дорог и земель, разные
лесничества. Поэтому:

- **Фаза 1 — Святогоровский узел** (приоритет). Знаки в пределах деревни и её
  ближайших окрестностей: указатели к Поклонному кресту, Часовенке Николая
  Чудотворца, Купели, въездной стенд, интерпретационные таблички у каждого
  объекта, зоны отдыха. Согласования — администрация поселения + земли,
  принадлежащие приходу/связанным лицам. Это **то, что приход может реально
  реализовать своими силами**.
- **Фаза 2 — расширение к Дмитрову и Лавре**. Знаки начала маршрута в Дмитрове,
  промежуточные указатели по трассе, финиш у Лавры. Согласования — несколько
  МО, владельцы дорог, лесфонд. Требует партнёрства с епархией / Минкультуры МО
  / турадминистрациями. Долгосрочный план.

Пакет в этой папке покрывает **обе фазы**, но Фаза 1 проработана конкретно,
Фаза 2 — на уровне рамок.

## Естественная последовательность работ

1. **Утвердить концепцию (00)** с настоятелем / профильным сотрудником прихода.
2. **Полевая разведка маршрута (01)** — пройти GPS-трекером, отметить точки
   объектов, кандидаты для установки знаков, фото каждой точки.
3. **Кадастровый аудит (04)** — выяснить собственников земли под каждым знаком.
4. **Финализация дизайн-системы (02)** — макеты каждого знака с привязкой к точкам.
5. **Компьютерный монтаж (05)** — наложить макет знака на фото каждой точки
   (прямое требование Методички для получения разрешения).
6. **Пакет на разрешение (05)** — собрать заявление, фото, монтажи, согласия
   собственников, эскизы. Подать в уполномоченный орган МО.
7. **После получения разрешения** — тендер на производство (07), монтаж, ввод в
   эксплуатацию (08).

## Связь с лендингом

QR-коды на знаках ведут на лендинг (`https://святогорово.рф/`) — на якоря
соответствующих разделов или на специальные подстраницы. Это часть аргументации
проекта: тропа физически соединена с цифровой инфраструктурой деревни. Подробнее
в `06-content/qr-content.md`.

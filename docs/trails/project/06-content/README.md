# 06 — Контент

**Статус: 🟡 Структура и QR-маппинг готовы.** Тексты знаков пишутся параллельно
с дизайном, после согласования нарратива (`../00-concept/narrative.md`) с
настоятелем.

## Файлы раздела

- `qr-content.md` — **готов**. Маппинг QR-кодов знаков на разделы лендинга,
  опциональные расширения (выделенные страницы тропы, аудиогид).
- `sign-texts.md` — **в работе**. Финальные тексты на знаках всех типов
  (рус. + англ.). До тех пор используется тон-голоса и черновики из
  `../00-concept/narrative.md`.

## Требования к текстам на знаках

- **Лимит длины:** ≤ 80 символов для заголовка, ≤ 600 символов для основного
  текста на интерпретационной табличке T4. Больше — не читается на ходу.
- **Билингва:** русский + английский, английский — параллельный, а не
  дословный перевод (см. `../00-concept/narrative.md`).
- **Тон:** короткие предложения, без музейной пыли, без благочестивого штампа,
  спокойная серьёзность.
- **Без коммерческих упоминаний** (запрет рекламы на знаках навигации).
- **С указанием источников** — где факт основан на документальной истории, а
  где на устной традиции / благословении. Это вопрос честности.

## Процедура утверждения текстов

1. Дизайнер / автор готовит черновик каждого текста.
2. Просмотр настоятелем (религиозная составляющая, корректность упоминания
   святых, корректность атрибуции событий).
3. Просмотр историком/краеведом (фактологическая корректность).
4. Просмотр редактором (тон, грамотность, ритм).
5. Финальное утверждение → подача в эскизный проект.

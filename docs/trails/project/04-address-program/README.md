# 04 — Адресная программа

**Статус: ⛔ Заблокирован двумя этапами:**

1. Завершением полевой разведки маршрута (раздел 01).
2. Кадастровым аудитом каждой точки установки.

## Что в итоге должно появиться в этом разделе

- `address-program.md` — сводная таблица всех знаков проекта:
  - № п/п
  - Тип знака (T1-T6 из `../02-signage-system/sign-types.md`)
  - GPS-координаты места установки
  - Кадастровый № участка (из выписки ЕГРН по координатам)
  - Категория земель (поселения / транспорта / лесфонд / частная)
  - Собственник участка (физлицо / юрлицо / РФ / МО / муниципалитет)
  - Статус согласования (запланировано / запрошено / получено)
- `landowners.md` — реестр уникальных собственников земель проекта, с
  контактами и статусом коммуникации.

## Как составить кадастровый раздел

1. По каждой точке установки знака из раздела 01 — запросить **публичную
   кадастровую карту Росреестра** (`pkk.rosreestr.ru`) и узнать кадастровый
   номер участка.
2. По каждому уникальному кадастровому номеру — заказать **выписку из ЕГРН**
   (через Госуслуги / МФЦ / на сайте Росреестра). Выписка покажет собственника
   и категорию земель.
3. По каждому типу собственника — определить путь согласования (см. также
   `../05-approvals/application-template.md`):
   - Земли поселения / муниципальные → администрация Дмитровского городского
     округа.
   - Земли транспорта (вдоль дорог) → собственник дороги (региональный
     департамент дорожного хозяйства МО, если регдорога; местный — если
     поселковая).
   - Земли лесного фонда → территориальное лесничество.
   - Частные → конкретный собственник.

> Для большинства точек на территории прихода и в самой деревне это будет
> либо приходская собственность, либо муниципальная — оба пути относительно
> быстрые. Сложности возникнут только при выходе на лесные тропы.

## Бюджет на этот раздел

Сам по себе кадастровый аудит — относительно дешёвый:

- Выписка из ЕГРН — `460 ₽ / шт.` (электронная, физлицу) или `820 ₽ / шт.`
  (бумажная). Для 15-25 точек проекта — `7-25 тыс. ₽`.
- Время — 3-5 рабочих дней на выписку, плюс работа специалиста по сводке.

Это самая критичная инвестиция первой стадии: **без неё пакет на разрешение
сформировать невозможно**.

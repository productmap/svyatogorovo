# 01 — Маршрут (route)

**Статус: ⛔ Заблокирован полевой работой.**

Этот раздел не может быть составлен «из кабинета» — он требует:

1. **Прохода маршрута с GPS-трекером.** Записать трек Святогоровского отрезка
   от въезда в деревню до финишной точки (граница расширения к Дмитрову или к
   Лавре).
2. **Точечной разведки объектов.** Снять GPS-координаты Поклонного креста,
   Часовенки Николая Чудотворца, Купели, кандидатных смотровых точек.
3. **Фотофиксации точек установки знаков.** По каждой потенциальной точке —
   2 фото (общий план + место установки опоры) с записью координат.

## Что в итоге должно появиться в этом разделе

- `route.md` — текстовое описание маршрута: длина, профиль высот, время
  прохождения, особенности (грунт, перепады, броды).
- `route.geojson` — GPS-трек в формате GeoJSON для встраивания в карты
  лендинга и в печатные путеводители.
- `points.md` — реестр всех точек: объекты + кандидатные места установки
  знаков с координатами и фото.

## Полевой чек-лист

- [ ] GPS-трекер (телефон с приложением, например, Locus Map / OsmAnd, либо
      отдельное устройство Garmin) с записью каждые ≤ 5 секунд.
- [ ] Камера (можно телефон) для фотофиксации.
- [ ] Бумажный блокнот для пометок и встреч с местными.
- [ ] Распечатанная карта Святогорово с координатами объектов на лендинге
      (`56.404361, 37.821090`) и спутниковый снимок Дмитровского городского
      округа.
- [ ] Контакты прихода — для возможных уточнений на месте.

После выполнения этих шагов составляются три файла раздела и обновляется
адресная программа (`../04-address-program/`).

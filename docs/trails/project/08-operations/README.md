## Ориентировочный регламент ТО

| Что | Как часто | Кто |
|---|---|---|
| Визуальный осмотр (целостность, читаемость, чистота) | 1 раз в месяц | Назначенный смотритель тропы (волонтёр прихода, староста и т. п.) |
| Чистка лицевой поверхности | По мере необходимости (минимум 2 раза в год: весна / осень) | Тот же |
| Проверка крепёжных узлов | 1 раз в год (весна) | Тот же |
| Полная диагностика (опоры, фундаменты, плёнка) | 1 раз в 3 года | Подрядчик / специалист |
| Замена выгоревшей плёнки | По факту, обычно 5-7 лет от монтажа | Подрядчик |

## Журнал состояния

В этой папке после монтажа заводится `journal.md` — рабочий журнал, куда
смотритель тропы пишет каждый осмотр (дата, состояние, замечания, действия).
Это и для качества эксплуатации, и для отчёта перед уполномоченным органом
МО, если потребуется.

## Контакт ответственного

После запуска системы здесь указывается:

- ФИО смотрителя тропы.
- Контактный телефон.
- E-mail для запросов от уполномоченных органов и подрядчиков.
